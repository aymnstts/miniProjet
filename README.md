Ce mini-projet implémente une chaîne CI/CD complète combinant GitHub Actions et Jenkins pour automatiser le cycle de vie d'une application Java/Maven. L'architecture intègre un dépôt GitHub avec deux branches (main/dev), des workflows automatisés pour le build et les tests, un pipeline Jenkins pour la compilation et l'archivage des artefacts, et des notifications Slack pour le suivi en temps réel. Technologies utilisées : Git, GitHub Actions, Jenkins, Java 17, Maven, Docker et Slack. Ce projet pédagogique illustre concrètement les principes DevOps essentiels et pose les bases pour des implémentations plus avancées incluant le CD, Docker Compose et le monitoring.
